# Libraries

Shared libraries consumed by the apps under [`app/`](../app/README.md) live here.

- [`@nimbus-labs/ui`](ui/README.md) — shared MUI theme and navigation primitives
- [`@nimbus-labs/deeptime`](deeptime/README.md) — framework-agnostic geologic time / temporal graph
  model

See the [repo root README](../README.md) for how to add a library as a dependency of an app.
